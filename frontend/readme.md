# 🎨 Frontend - KSS Procurement OS

This directory contains the React + TypeScript frontend application built with Vite and Tailwind CSS.

For full project documentation, architectural overview, and setup instructions, please refer to the main [Root README.md](../README.md).

---

## ⚡ Frontend Quickstart

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
